# 蠱毒（こどく）

iPad の Safari で動く、4 人で戦う対戦ゲームの試作品です（一人称）。
今は練習モード（あなた＋bot 3 体）で、試合の骨組み（フェーズ・ポイント・報酬・結果）と戦闘（近接・弓・防御）までできています。
キャラは Tripo AI で作った 6 種類の模型で、動き（構え・歩き・走り・斬り・防御・ひるみ・倒れる・弓を引く）が付いています。武器と盾も Tripo AI の模型です（メイスとロングボウはまだ仮の形）。

## 試合のルール（今できているところ）

- 4 人（あなた＋bot 3 体）で始まる。一度倒れたら脱落
- 5 つのフェーズ。歩ける範囲は最初から森全体（半径 175m、端から端まで 350m。走って約 65〜75 秒）。外周は高さ約 10m の丸太の柵で囲み、柵より上も見えない壁で通れない
- フェーズが進むと時間帯が変わる（20 秒かけて、空の写真も重ねながらゆっくり移り変わる）：朝 → 昼 → 夕暮れ → 深夜 → 深夜（最終）。時間帯ごとに、その時刻に撮った本物の空の写真に切り替わり、太陽（夜は月）・霧・明るさも変わる
- 太陽を見るとまぶしい：光の輪と光の筋、まっすぐ見るほど画面が白く飛ぶ。太陽が直接見えるときだけ（柵・地面・木の幹や葉にさえぎられると出ない）。夜の月はまぶしくない
- 最終フェーズの時間が切れても、生き残りが 1 人になるまで延長する
- 1 人になった瞬間に終わり、最後の生き残りに大きな加点。ポイントが一番高い人の勝ち
- フェーズを生き残るたびに加点と、画面中央の報酬（3 つから 1 つ選ぶ）
- 右上に全員のポイントをランキング順で表示

- キャラ（楯劍騎士・劍騎士・長柄騎士・打擊騎士・弓兵・祓魔僧）ごとに、選べる武器・楯・鎧の硬さ・体力・速さが違う（設計の全体は `docs/DESIGN.md`）
- 武器は試合の前に選ぶ（題の画面でキャラを選んだあと、右手の武器・左手の楯・弓兵は持替の武器）。試合の途中では替えられない。鍛冶（作る・強化）は無い
- 近接は「振りかぶり → 当たり → 戻り」。間合いと角度に入った相手に当たる
- 弓は押している間に引き、離すと放つ。引くほど強く速い。矢は重力で落ちる
- 防御は盾を持つキャラだけができる（武器では受けられない）。前からの攻撃を減らし、スタミナを使う。スタミナが尽きると崩れてひるむ
- 打撃武器は防御の上からも響く。まともに受けるとひるむ
- 強攻撃（左手）：振りかぶりが長く隙も大きいが、ダメージ 1.7 倍。なぎ払いは広く、叩きつけは防御の上からさらに響く（数値は `js/game/data.js` の `HEAVY`）
- 画面：左上にミニマップ（森全体。自分だけを矢印で表示）、上の真ん中にフェーズ・時間帯・残り時間、右上にランキング
- 回避は装備の重さで変わる：軽装（弓兵・聖職者）は軽やかな前転、中装（盾剣騎士・剣騎士）は前転、重装（長柄騎士・打撃騎士）は回避ステップ。少しの間、攻撃が当たらない。スタミナを使う
- 倒されたら脱落して、生き残りを肩越しに観戦する
- bot は一番近い相手を狙う（近接は詰めて攻撃・ときどき防御、弓兵は距離を取って射る）。bot 同士も戦う

数値（キャラ・武器・戦闘・フェーズ・ポイント・報酬）は `js/game/data.js` にまとめてある。

- エンジン：PlayCanvas Engine **2.23.3（リポジトリ内に固定）**
- 公開：GitHub Pages（ビルド作業なし。置いたファイルがそのまま動く）
- 外部ライブラリ：PlayCanvas のみ
- 質感画像：Poly Haven（CC0）の地面・樹皮・岩（`assets/textures/CREDITS.md`）
- 空：Poly Haven（CC0）の HDR 写真 4 枚（朝・昼・夕暮れ・深夜）から作った背景と照明（`assets/sky/CREDITS.md`）
- 木と茂み：Blender（Sapling Tree Gen）で作った 7 種類の模型。地面の草も Blender で描いた画像。葉は ambientCG（CC0）の写真、樹皮は Poly Haven（CC0）の写真（`assets/trees_blender/CREDITS.md`）。前の Tripo AI の木は `assets/trees/` に残してある（今は使っていない）
- 草・シダ・落ち枝・岩・切り株：Poly Haven（CC0）の 3D 模型（`assets/props/CREDITS.md`）
- キャラ：Tripo AI で作った 6 種類の模型と、魔境争覇から移した動き（`assets/characters/CREDITS.md`）
- 武器・盾：Tripo AI で作った模型（`assets/weapons/CREDITS.md`）

ゲームの中の名前・ボタン・見出しは、漢字だけ（旧字体）にしています（知らせや説明の文は今の日本語。数字は算用数字）。名前の一覧は `docs/DESIGN.md` の「名前の決まり」。

### 武器を選ぶ

- 題の画面でキャラを押すと、その下に選べる武器が出る（右手・左手・持替）。選ばなければ、並びの最初の物
- 模型と動きがまだ無い武器（片刃劍・兩手大劍・長槍・斧槍・戰鎚・長柄鎚・連枷・戰斧・弩・小楯・大楯）は「未完」と出て、選べない
- bot の武器は、選べる物から乱数で決まる
- 選べる物の一覧は `js/game/data.js` の `LOADOUTS`

### 音

- 足音・声・息遣い・振る音・当たる音・鳥・虫・カラスなどは、**録音の音**（OpenGameArt の CC0。出典は `assets/sounds/CREDITS.md`）。風・葉のざわめき・弓の弦・時計台の鐘・ぴったり回避の音は、その場で作る（Web Audio）
- 試合を始めるボタンを押すと鳴り始める（iPad の決まり）。設定の「音」で大・中・小・消す
- 足音：草・落ち葉・土の道・板の床（家の中）・石畳（村の広場）で違う。重い鎧はときどき鎖帷子が鳴る。ほかの人の足音も近ければ聞こえる
- 声（キャラごとに高さが違い、倒れる声はキャラごとに違う）：回避ステップの息を止めるような声、スタミナが 4 割以下になってからの攻撃の声、攻撃を受けて痛がる声、倒れる声
- 息遣い：スタミナが減るほど荒くなる。**隠れている間は 1.2 倍大きく、近くの bot に聞かれると見つかりやすい**（息が荒いほど）
- 振る：武器で違う風の音（剣は鋭く、メイスは重く、槍は短い突き）。当たる：斬る・突く・打つで違い、当たった物（盾・金属の鎧・革や布・木の幹や壁）で変わる
- 回避：前転は体が転がる布ずれと地面に着く音、回避ステップは声と足のすり音。**ぴったり回避**（無敵の間に攻撃をかわした）は、画面が一瞬白く光り、特別な音
- 環境音：風・葉。**鳥のさえずりは朝だけ、虫（コオロギ）は夜だけ、カラスは昼・夕暮れ・夜**。家の中では外の音がこもる
- フェーズの始まり：**時計台の鐘**（チャイムの節と、時を打つ大きな鐘。第二フェーズは 2 回、第三フェーズは 3 回…）
- 敵の頭上の名前と体力は出さない
- iPad の消音スイッチが入っていると鳴らないことがある（対応している Safari では、消音スイッチがあっても鳴るようにしている）

### 姿勢と、bot の目と耳

- しゃがむ：歩く速さが半分になり、走れない。目が低くなり、体も低い（塀や茂みに隠れやすい）。足音が小さい
- 伏せる：とても遅い（這う）。伏せる・起き上がるのに約 0.7 秒（その間は動けない）。体がほぼ地面の高さになり、低い物や背の高い草に隠れる。足音は布ずれだけ
- しゃがんでいて攻撃・左手・回避を押すと、すぐ立ってそのまま動く。伏せているときは、まず起き上がる
- bot は**目で見えた相手**か、**音が聞こえた相手**にだけ気づく（壁越しに分かることはない）
  - 目：前の 120 度の中で、キャラごとの見える距離まで（弓兵 55m・聖職者 45m・盾剣騎士 40m・剣騎士と長柄騎士 35m・打撃騎士 30m）。相手の体の**半分以上が直接見えたとき**だけ気づく。家の壁・家具・木の幹・岩・柵・丘・大草原の背の高い草など、間にある物がさえぎる
  - 耳：足音（走る 22m・歩く 10m。しゃがむと約 3 分の 1、伏せると約 7 分の 1。重い鎧ほど大きい）、振る・当たる・回避・弓・探す・隠れる音。攻撃されたら、相手の居場所が分かる
  - 見失ったら：最後に見た（聞いた）所へ行き、しばらく見回す。見つからなければ元の行動に戻る
- 体の動き：しゃがみ（その場）は Meshy AI で作った動き、しゃがみ歩き・伏せる・伏せ（肘をつく）・這う・起き上がるは Blender で手で付けた動き
- bot は、音や見失った相手を探しに行くとき、近くまで来たらしゃがんで忍び寄る（足音が小さい）。相手が見えたら立って戦う

### 隠れる・探す

- 家のベッドの下とタンスの中に隠れられる。隠れている間は見つからず、攻撃も当たらない。三人称（家具の上の少し後ろから外を見る。左右に少し見回せる）
- 隠れている間に相手がすぐ前に来たら、攻撃ボタン（「暗殺」）で飛び出して暗殺。ただし猶予の間（約 0.45 秒）に回避されると失敗する
- 「探す」でベッドやタンスを開ける。誰かいれば、その人は無防備（約 2.6 秒、何もできない）になり、攻撃ボタン（「とどめ」）で致命の一撃を入れられる
- bot：誰かが隠れるところを見たら、探しに来る。体力が少ないと、近くの家へ逃げ込んで隠れ、そばを通る人を暗殺しようとする。暗殺されそうになると、ときどき回避する

### 壁裏隠れ

- 家の外の壁と中の壁に背を付けて待ち構える（近くで「壁に隠れる」）。三人称になり、体の横を通して壁に沿った向きを覗く（見回せる）
- 移動スティックを倒すと、壁に背を付けたまま壁際を歩く（静か。足を寄せては開く動き）。スティックの向きは画面の向き（倒し始めたときの向きを、離すまで使う）。進んだ向きを覗く
- 壁から離れるのは「離壁」か暗殺のときだけ（攻撃を受けたとき・倒れたときも）。ほかのボタンでは離れない
- 近く（約 3m）に相手が来たら、いつでも攻撃ボタン（「暗殺」）で飛びかかって暗殺。猶予の間（約 0.45 秒）に回避されると失敗する
- 近くに相手がいないときに攻撃・左手・回避を押すと、壁から離れてそのまま動く。攻撃を受けても壁から離れる
- 壁に隠れていても見つかることはある（bot の目と耳はふだんと同じ）
- bot：見えない相手の足音が近づいてくると、ときどき近くの壁に背を付けて待ち伏せし、近くに来た相手を暗殺する

左右を同時に使えます（歩きながら見回せる）。

### URL の切り替え

| 付け足すもの | 意味 |
|---|---|
| `?q=low` / `?q=high` | 画質（既定は medium） |
| `?stats=0` | 左上の性能表示を消す |
| `?seed=123` | 森の配置を変える |
| `?wind=0.5` | 風の強さ（既定 1.5、0 で無風） |
| `?debug=1` | 確認用のボタンを画面の上に出す（bot を倒す・自分が倒れる・次のフェーズへ。設定画面の「テスト用」にも同じものがある） |
| `?view=third` | 三人称で見る（確認用。遊ぶときは一人称だけ） |
| `?phase=30` | フェーズの長さを 30 秒にする（確認用。設定画面の「テスト用」でも選べる） |

例：`https://naosuke0506-max.github.io/forest-game/?q=low`

エリア（`js/world/zones.js`）：中央＝森と草原が混ざる森、北＝深い森（木が 3 倍以上密で、霧が濃く暗い）、東＝大草原（木はまばら、草が多い）、
南西＝村（横 84m・奥行き 54m の長方形の木の柵で囲み、森の中央の側に屋根付きの門がひとつ。入り口からの表通りと横の通りが井戸のある広場で交わり、通りに沿って大きさの違う家が並ぶ。半分ほどは二階建て。どの家にも入れ、二階へは階段で上がれる（扉から入ると、左の壁沿いの階段の前に踊り場がある）。中にはベッド・タンス・机・暖炉など。家の外は凹凸のある作り：しっくいの壁に浮き出た木組み（柱・筋交い・正面の斜め十字）、二階が前へ張り出す二階建て（根太の端と持ち送り）、石積みの家（隅石・石のまぐさ）、板張りの二階、厚みのある屋根（瓦は破風板・垂木・棟瓦、わらぶきは太い棟）、妻壁の木組みと小窓、窓台・十字の桟・色とりどりの鎧戸・花箱、扉の石の段と庇、笠石の付いた煙突。家の周りに樽・長椅子・薪の山・干し草）、中央から各エリアへ土の道。左上の小さな地図は今いるエリアだけを大きく映し（ほかは暗く）、エリアが変わると切り替わる。タップすると画面の 8 割ほどの大きな地図でマップ全体（エリアの名前・境目・道）を見られる。別のエリアに入ると左に知らせが出る。

広い森でも重くならないように：木は精細な形で描くのを近い順に 30 本まで（深い森で増えすぎないように）、深い森の中では描く遠さも短くする。木・岩・切り株は約 125m より遠いものと、カメラの後ろにあるもの（影が届く近さより遠いもの）を描かない。
草・シダ・落ち枝は、自分の周りの 12m 四方の区画ごとに、種から決まる置き方でその場で作る（離れた区画は捨てる）。

左上の表示は「fps（1 秒あたりの描画回数）／ draw（描画命令の数）／ tri（場面の三角形の数）／画質と描画解像度の倍率」です。

新しい木を足すときは、元の GLB を `source_models/trees/` に置き、`tools/process_trees.mjs` の `TREES` と `js/world/trees.js` の `TREE_TYPES`、`js/config.js` の `world.trees` に名前を足します。

## キャラの模型を作り直す（開発用）

Tripo で骨付けした GLB を `source_models/characters/` に置き、`tools/characters/characters.json` に書いてから、Blender 4.2 で次を実行します（iPad ではできないので Claude Code の作業環境で動かす）。

```
blender -b --python tools/characters/build_character.py -- <キャラ名> <魔境争覇の剣士の GLB> assets/characters
```

- 動きを魔境争覇の剣士の模型から Tripo の骨へ移す（腕を下ろした姿勢と T ポーズの違いは骨ごとに補正）
- 武器・盾・弓を持たせる位置（`socket_R` / `socket_L` / `socket_bow`）を、元の模型の武器の位置から測って手に付ける
- 三角形を 1.5 万に減らし、質感の画像を 2048 にする
- `source_models/motions/motions.blend` があれば、その動き（しゃがみ・しゃがみ歩き・伏せる・伏せ・這う・起き上がる・壁に背を付けて覗う 左右）も移す（骨は Mixamo 式）

### 姿勢の動きを作り直す

しゃがみ（その場）は利用者が Meshy AI で作った動き（`source_models/motions/crouch_meshy.fbx`）。ほかの動きは Blender で手で付けています（骨が向く方向を体の向きで決めて、1 フレームずつ解く）。

```
blender -b --python tools/characters/make_motions.py -- source_models/motions/crouch_meshy.fbx source_models/motions/motions.blend
```

作り直したら、上の手順で 6 キャラの模型を作り直します。

### 手と足の位置で付ける動き（片手劍の技・体の動き・楯の技）

次の動きは、Tripo の骨に直接付けています。手（剣の持ち手・楯）の位置と向き、足の位置、腰の位置と向きを何か所かの時刻で決め、その間をなめらかにつなぎます。腕と脚は、手と足が届くように関節を曲げます（道具は `tools/characters/ik_rig.py`）。

- `tools/characters/onehand_moves.py`：片手劍の技（踏込突・逆袈裟・袈裟斬（溜めに入る・溜め・放つ）・旋風斬）。`characters.json` で `"onehand": true` のキャラ（楯劍騎士・劍騎士）
- `tools/characters/longsword_moves.py`：長劍の技（唐竹・横薙・長突・斬返。両手で持ち、左手を柄に添える）。`characters.json` で `"longsword": true` のキャラ（劍騎士）
- `tools/characters/hide_moves.py`：タンス・ベッドに隠れる・出る・探す（全キャラ）、引きずり出されて止めを刺される（全キャラ）、引きずり出して止めを刺す（片手劍を持つキャラ）。動きの座標は、家具の前の「出る所」に立って家具の方を向いた向き
- `tools/characters/body_moves.py`：全キャラの体の動き
  - しゃがみ歩き（深くしゃがむ）・伏せから起き上がる（今までの物と入れ替え）
  - 被弾（軽い・重い）とよろめき。それぞれ前・後ろ・左・右から
  - 楯劍騎士だけ：防禦で受ける（弱い・強い）・楯擊・楯押・受流・楯突貫
  - 這う・伏せ・伏せるは、顔がまっすぐ前を向くように首と頭を直す

腕が胴に埋もれないように、模型から胴（腰・腹・胸）の太さを高さごとに測り、手首や肘が胴の中に入るときは、手首を胴の外へ出し、肘を外へ回します。
`characters.json` で `"fixArms": true` のキャラ（劍騎士）は、魔境争覇から移した動きなど、もとからある動きにも同じ直しをかけます（両手持ちの動きは、左手も一緒に動かして柄から離れないようにする）。

上の手順でキャラを作り直すと入ります。形を直すときは、それぞれのファイルの数字を変えます。

## GitHub Pages で公開する手順（iPad の Safari で）

1. このリポジトリのページを開き、上の **Settings** を押す
2. 左の一覧から **Pages** を押す
3. **Build and deployment** の **Source** を **Deploy from a branch** にする
4. **Branch** を **main**、フォルダを **/ (root)** にして **Save**
5. 1〜2 分待って、同じ Pages の画面の上に出る URL（`https://naosuke0506-max.github.io/forest-game/`）を開く

更新を反映させたいときは、main に変更が入れば自動で公開し直されます（数分かかります）。
古い画面が出るときは、Safari で再読み込みしてください。

更新の直後は、Safari が新しいページと古いプログラムを混ぜて読み込むことがあります（ボタンが反応しない など）。
そのためページとプログラムに版の番号（`index.html` の `window.__BUILD` と `js/version.js`）を持たせ、
合わないときはプログラムを取り直して 1 回だけ読み込み直します。**変更を公開するたびに、両方の番号を上げます。**

# 武器・盾の模型の出典

| ファイル | 武器 | 出典 |
|---|---|---|
| `armingsword.glb` | アーミングソード | 利用者が Tripo AI で作成 |
| `longsword.glb` | 長劍（ロングソード） | 同上（2026-11-08 に作り直した物へ入れ替え） |
| `spear.glb` | スピア | 同上 |
| `kite_shield.glb` | カイトシールド | 同上 |
| `mace.glb` | 鎚矛（メイス） | 同上（2026-11-09） |
| `warhammer.glb` | 戰鎚（ウォーハンマー） | 同上（2026-11-09） |
| `lucerne.glb` | 長柄鎚（ルツェルンハンマー） | 同上（2026-11-09） |
| `dagger.glb` | 短劍（ダガー） | 同上（2026-11-09） |

- 元の模型（Tripo の書き出しそのまま）は `source_models/weapons/`
- `tools/process_weapons.mjs` で、持ち手の位置と向きをそろえ、三角形を減らし、質感の画像を小さくした
- 鎚矛・戰鎚・長柄鎚・短劍（2026-11-09）は、送られたファイルの最後が少し欠けていた（最後の画像＝金属らしさ・粗さの画像だけが読めない）。
  その画像を外して読める形に直し（金属らしさ 0・粗さ 0.6）、`tools/decimate_weapon.py`（Blender）で 4 万三角形に減らした物を `source_models/weapons/` に置いた。
  ゲーム用は、さらに Blender で 3000 三角形（短劍は 2000）に減らしてから `tools/process_weapons.mjs` を通した
- 戰鎚・長柄鎚は、持つ位置を柄の先へ移して作り直した（2026-11-09。利用者の指示で持ち方を直したため。形と画像は同じ。持ち手の点だけが動いた）
- ロングボウは、まだ模型がない（仮の形で表示する）

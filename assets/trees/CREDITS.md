# 木の模型

利用者が **Tripo AI** で作った模型です（ChatGPT で作った参考画像から、HD モデルとして生成）。
利用条件は、作ったときの Tripo AI のプランの規約に従います（公開・販売の前に規約を確認すること）。

| 名前 | 木 | 高さ（ゲーム内） | 近く用の三角形 | 遠く用の三角形 |
|---|---|---|---|---|
| `fir` | 針葉樹（モミ） | 15m | 6,741 | 約 1,000 |
| `red_pine` | アカマツ | 16m | 9,100 | 約 1,200 |
| `broadleaf` | 広葉樹（ブナ） | 12m | 12,120 | 約 1,300 |
| `birch` | シラカバ | 13m | 10,560 | 約 1,100 |
| `dead` | 枯れ木 | 10m | 11,137 | 約 900 |
| `sapling` | 若木・低木 | 2.4m | 2,045 | 約 370 |

正確な数は `trees.json` にあります。

## ファイル

| ファイル | 中身 |
|---|---|
| `<名前>_lod0.glb` | 近く用の形（色の画像は含まない） |
| `<名前>_lod1.glb` | 遠く用の形 |
| `<名前>_color.webp` | 色の画像（1024px、近く用と遠く用で共有） |
| `trees.json` | 高さ・幹の太さ（当たり判定）・葉の広がり（木どうしの間隔）・三角形の数 |

元の GLB（Tripo から書き出したもの）は `source_models/trees/` にあります。ゲームは読み込みません。

## 作り直すとき

```
cd tools && npm ci
node process_trees.mjs ../source_models/trees ../assets/trees
```

高さ・三角形の目標は `tools/process_trees.mjs` の `TREES` で変えられます。
